## Do I need a commercial license?

The AGPL-3.0 is strong copyleft. If you distribute Sapient Studio or a modified
version (including through an app store), or run a modified version as a
network service (its API server counts), the AGPL requires you to make the
complete corresponding source code available to your users under the AGPL-3.0.

You most likely need a commercial license to:

- ship Sapient Studio, or a product built from it, as **closed source**;
- **rebrand** it or include it in a proprietary product you sell or license;
- run a modified version as a service while keeping your changes private.

You most likely do not need one if you use it as is, or release your changes
under the AGPL-3.0.
